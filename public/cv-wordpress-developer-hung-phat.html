Tóm Tắt Chuyên Môn

Tốt nghiệp Kỹ sư Hệ thống Thông tin (ĐH Công nghiệp TP.HCM - IUH) với năng lực thiết kế và triển khai website WordPress toàn diện từ giao diện người dùng đến hạ tầng kỹ thuật. Nắm vững WordPress, Elementor kết hợp nền tảng lập trình web cốt lõi (HTML5, Modern CSS, JavaScript, PHP), giúp chủ động tùy biến giao diện theo mẫu thiết kế, viết Custom CSS và can thiệp mã nguồn khi cần thiết. Có gu thẩm mỹ tốt, trực tiếp thiết kế banner, hình ảnh bài viết và tối ưu hóa tài nguyên đồ họa web qua Figma và Canva. Từng trực tiếp cấu hình tên miền (Domain DNS), chứng chỉ bảo mật SSL, cài đặt hosting và backup dữ liệu thực tế. Tác phong làm việc trách nhiệm, kỷ luật với tiến độ, kiểm thử kỹ lưỡng trước khi bàn giao và phối hợp hiệu quả cùng bộ phận Kinh doanh / Khách hàng.

Kỹ Năng Chuyên Môn
  • Nền tảng WordPress & Page Builder: Cài đặt, cấu hình WordPress, thành thạo Elementor, WPBakery; tùy biến giao diện theo mẫu tham khảo, triển khai website doanh nghiệp, landing page, web dịch vụ và bán hàng cơ bản (WooCommerce).
  • Lập trình & Can thiệp Giao diện: HTML5, CSS3 (Flexbox, Grid), JavaScript cơ bản, PHP/MySQL. Khả năng viết CSS tùy chỉnh (Custom CSS), chỉnh sửa file template theme (functions.php, header, footer), sửa lỗi hiển thị và cấu trúc trang theo yêu cầu.
  • Thiết kế Đồ họa & Banner Web: Sử dụng thành thạo Figma, Canva (và Photoshop cơ bản); tự thiết kế banner trang chủ, banner sản phẩm, hình ảnh bài viết, icon, nút bấm; crop, resize và nén dung lượng ảnh (WebP/TinyPNG) giúp tối ưu tốc độ tải trang.
  • Tối ưu Giao diện Responsive: Căn chỉnh hiển thị chuẩn trên mọi kích thước màn hình (Desktop, Laptop, Tablet, Mobile); kiểm tra độ tương thích trên các trình duyệt phổ biến (Chrome, Safari, Firefox, Edge).
  • Tích hợp Công cụ & Tiện ích Web: Cài đặt form liên hệ (Contact Form 7, WPForms), nút gọi Hotline, nút chat Zalo/Messenger, bản đồ Google Maps, Google Analytics, Facebook Pixel.
  • Hạ tầng Hosting, Domain & Bảo mật: Trỏ DNS tên miền, cấu hình chứng chỉ SSL/HTTPS (Let's Encrypt / Cloudflare), quản trị cPanel/DirectAdmin, backup dữ liệu định kỳ, di chuyển website (migrate) giữa các hosting.
