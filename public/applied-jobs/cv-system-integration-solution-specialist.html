Tóm Tắt Năng Lực Chuyên Môn

Kỹ sư Hệ thống Thông tin tốt nghiệp loại Giỏi tại Đại học Công nghiệp TP.HCM (IUH, GPA 3.26/4.0), có kiến thức bài bản về phân tích quy trình nghiệp vụ, kiến trúc CSDL quan hệ và kỹ thuật tích hợp hệ thống phần mềm doanh nghiệp. Kinh nghiệm thực tế trong việc rà soát tài liệu đặc tả kỹ thuật (SRS, SDD, OpenAPI 3.0), kiểm thử luồng dữ liệu API contract trên Postman, cấu hình Data Mapping, xây dựng cơ chế đồng bộ bất đồng bộ qua hàng đợi thông điệp RabbitMQ và xử lý dữ liệu đối soát trên CSDL (PostgreSQL, MySQL). Nắm vững nguyên lý hoạt động của các phân hệ ERP (Odoo), quy trình chuỗi cung ứng SCM và tích hợp cổng thanh toán trực tuyến. Tác phong làm việc cẩn trọng, kỷ luật, giao tiếp rõ ràng và sẵn sàng làm việc toàn thời gian (bao gồm lịch làm việc sáng Thứ 7 theo quy định của doanh nghiệp).

Kỹ Năng Kỹ Thuật & Công Cụ Tích Hợp
  • Kỹ Thuật Tích Hợp Hệ Thống: Đặc tả API RESTful (OpenAPI 3.0), chuẩn hóa API Contract, Data Mapping dữ liệu JSON/XML giữa các hệ thống, cơ chế đồng bộ dữ liệu (Sync / Async Webhook), Idempotency-Key chống trùng lặp dữ liệu, cơ chế Retry & Dead-Letter Queue khi xảy ra sự cố mạng, ghi nhận logging phục vụ đối soát và truy vết lỗi.
  • Hệ Thống Doanh Nghiệp & Nghiệp Vụ: Hiểu rõ kiến trúc quy trình các phân hệ ERP (Odoo: Mua hàng, Bán hàng, Quản lý kho, Kế toán), quy trình quản trị dữ liệu danh mục Master Data, luồng quản lý đơn hàng chuỗi cung ứng (OMS / SCM) và tích hợp cổng thanh toán trực tuyến (VNPay IPN Webhook).
  • Mô Hình Hóa & Tài Liệu Kỹ Thuật: Sử dụng thành thạo Camunda BPMN 2.0, Draw.io để mô hình hóa luồng xử lý và ranh giới kết nối giữa các hệ thống; lập biểu đồ tuần tự UML (Sequence Diagram), sơ đồ luồng dữ liệu (DFD), sơ đồ quan hệ thực thể (ERD); rà soát và đóng góp ý kiến cho tài liệu SRS, SDD.
  • Cơ Sở Dữ Liệu & Đối Soát Dữ Liệu: Thiết kế CSDL chuẩn hóa 3NF (PostgreSQL, MySQL, MariaDB); thành thạo truy vấn SQL (JOIN, Aggregate, Subquery, Indexing) để bóc tách, đối soát chéo và phát hiện sai lệch số liệu giữa các hệ thống; bộ nhớ đệm Redis (Session Cache, Distributed Locks).
  • Công Cụ Kiểm Thử & Quản Lý Dự Án: Postman (Soạn thảo Test Collections, kiểm thử tự động API Contract, biến môi trường Environment), Git / GitHub, Docker Compose, Jira, Confluence; khả năng đọc hiểu tài liệu kỹ thuật Tiếng Anh chuyên ngành độc lập.
