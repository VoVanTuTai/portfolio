Mục Tiêu Nghề Nghiệp & Tư Duy Kỹ Thuật (Career Objective & Engineering Mindset)

Kỹ sư Hệ thống Thông tin tốt nghiệp Đại học Công nghiệp TP.HCM (IUH, GPA 3.26/4.0 · Xếp loại Giỏi · Đã hoàn thành 100% chương trình học, sẵn sàng làm việc toàn thời gian). Sở hữu nền tảng vững chắc kết hợp giữa phát triển phần mềm (Node.js, NestJS, TypeScript, Python, SQL) và tư duy kiểm thử tự động (Automation Testing / SDET). Có kinh nghiệm thực chiến về thiết kế & kiểm thử API (RESTful, OpenAPI 3.0, Postman), phân tích các kịch bản lỗi giao dịch (ACID isolation, deadlocks, row-level locking, tính lũy đẳng idempotency), xác thực cơ chế khóa phân tán (Redis SETNX), và điều tra sự cố runtime qua hệ thống log có cấu trúc. Chủ động ứng dụng AI/LLM để phát hiện ca biên (edge cases), sinh dữ liệu kiểm thử và tự động hóa gỡ lỗi. Đam mê xây dựng công cụ kiểm thử tự động có tính mở rộng cao, cam kết đóng góp dài hạn cho hệ sinh thái chất lượng phần mềm tại MoMo.

Kỹ Năng Chuyên Môn (Core Technical & SDET Competencies)
  • Kiểm thử Phần mềm & Tự động hóa (Software Testing & Automation): SDET, Automation Test, API Testing, Unit Testing (Jest), E2E Testing (Cypress), Kiểm thử tích hợp (Integration Testing), Thiết kế Kịch bản Kiểm thử (Test Cases, Test Scenarios, BDD Given-When-Then), Phân tích Giá trị Biên & Ca Lỗi (Edge Cases, Boundary Value Analysis, Negative Testing), Quản lý lỗi & Defect Triage trên Jira.
  • Lập trình & Kỹ thuật Phần mềm (Programming & Software Development): TypeScript, JavaScript (ES6+), Node.js (NestJS, Express.js), Python (Scripting, Automation), PHP (OOP/MVC), Lập trình hướng đối tượng (OOP), Clean Code, Cấu trúc Dữ liệu & Giải thuật, Quản lý mã nguồn với Git/GitHub/GitLab.
  • Kiểm thử API & Tích hợp Hệ thống (API Testing & Integration): RESTful API, OpenAPI 3.0, Swagger Contracts, Tự động hóa kiểm thử API với Postman (Newman, test scripts, pre-request scripts, environment variables), Xác thực DTO (class-validator), Webhooks (HMAC-SHA512 verification), và kiểm thử Idempotency-Key.
  • Cơ sở Dữ liệu & Toàn vẹn Dữ liệu (Databases & SQL): PostgreSQL, MySQL (Thiết kế Schema chuẩn 3NF, B-Tree Indexing, Giao dịch ACID, Khóa dòng bi quan SELECT ... FOR UPDATE), Viết câu lệnh SQL truy vấn nâng cao (Multi-table JOINs, Aggregations, Window Functions) phục vụ đối soát dữ liệu.
  • Tư duy Hệ thống & Hạ tầng (System Thinking & DevOps): Hàng đợi thông điệp bất đồng bộ (Message Queue RabbitMQ), Bộ nhớ đệm & Khóa phân tán (Redis SETNX Distributed Lock), Docker, Docker Compose, Quy trình CI/CD Workflows, Điều tra nguyên nhân gốc rễ (Root Cause Analysis - RCA) qua Runtime Logs.
  • Ứng dụng Trí tuệ Nhân tạo (AI in Testing & Quality Engineering): Ứng dụng mô hình LLM, Prompt Engineering để phát hiện các tình huống lỗi tiềm ẩn, tự động sinh bộ test payload, phân tích stack trace và kiểm thử schema API. Ngoại ngữ: Tiếng Anh đọc hiểu tài liệu kỹ thuật & giao tiếp công việc chuyên môn.
