Tóm Tắt Năng Lực Chuyên Môn

Tốt nghiệp Kỹ sư Hệ thống Thông tin (ĐH Công nghiệp TP.HCM - IUH, GPA 3.26/4.0 - Xếp loại Giỏi). Có nền tảng vững vàng về phát triển ứng dụng web doanh nghiệp theo mô hình kiến trúc Client–Server, MVC và 3-tier; am hiểu quy trình số hóa và vận hành phần mềm nội bộ (ERP, quản lý vận chuyển, quản lý đặt chỗ). Về Backend, nắm vững tư duy lập trình hướng đối tượng (OOP), cấu trúc phân tầng với Java / Spring Boot (Spring MVC, Spring Data JPA, RESTful API) và Node.js/PHP. Về Frontend, thành thạo xây dựng giao diện quản trị (Admin Dashboard), biểu mẫu nhập liệu nghiệp vụ (Form Validation) và báo cáo dữ liệu qua Vue.js, JavaScript (ES6+) và HTML5/CSS3. Nền tảng SQL tốt, có khả năng thiết kế schema quan hệ chuẩn hóa (ERD 3NF), viết truy vấn đối soát dữ liệu phức tạp và tối ưu hóa chỉ mục (Index). Dày dạn kinh nghiệm làm việc trực tiếp với người dùng tại các phòng ban để làm rõ yêu cầu nghiệp vụ, soạn thảo tài liệu hướng dẫn (SOP), kiểm thử UAT và hỗ trợ xử lý sự cố hệ thống.

Kỹ Năng Kỹ Thuật Trọng Tâm
  • Phát Triển Backend & Kiến Trúc Ứng Dụng: Java (Core OOP, Collection, Exception Handling), Spring Boot (Spring MVC, Spring Data JPA, Hibernate, RESTful API contracts), mô hình thiết kế 3 tầng (Controller – Service – Repository), kiểm soát giao dịch dữ liệu (ACID Transactions), bảo mật cơ bản (JWT, phân quyền người dùng).
  • Phát Triển Frontend & Giao Diện Web: Vue.js (Vue 2/3, Vue Router, Vuex/Pinia), JavaScript (ES6+), TypeScript cơ bản, HTML5, Modern CSS. Thiết kế trang quản trị, biểu mẫu nhập liệu có xác thực dữ liệu đầu vào (Validation), bảng dữ liệu tra cứu và báo cáo trực quan.
  • Cơ Sở Dữ Liệu & SQL: PostgreSQL, MySQL, SQL Server; thiết kế sơ đồ thực thể quan hệ (ERD chuẩn 3NF, xác định khóa chính/ngoại, quan hệ 1-1, 1-n, n-n), viết truy vấn SQL phức tạp (JOIN nhiều bảng, Subquery, Group By/Aggregate), tối ưu hóa tốc độ truy vấn qua chỉ mục (Index).
  • Hệ Thống Doanh Nghiệp & Tích Hợp: Hiểu rõ quy trình nghiệp vụ hệ thống nội bộ (ERP - Odoo: Mua hàng, Bán hàng, Kho, Kế toán), tích hợp hệ thống thông qua API/Webhook, làm quen với khái niệm tự động hóa quy trình (RPA), Git/GitHub, Docker, Docker Compose, Linux cơ bản.
  • Phân Tích Nghiệp Vụ & Hỗ Trợ Người Dùng: Khả năng trao đổi mạch lạc với người dùng không chuyên để làm rõ yêu cầu, chuyển hóa yêu cầu thành đặc tả kỹ thuật (Use Cases, User Stories), soạn thảo tài liệu quy trình thao tác chuẩn (SOP), dẫn dắt kiểm thử UAT và hỗ trợ người dùng sau triển khai. Đọc hiểu tài liệu kỹ thuật tiếng Anh tốt.
