Tóm Tắt Năng Lực Chuyên Môn

Kỹ sư Hệ thống Thông tin (ĐH Công nghiệp TP.HCM - IUH, GPA 3.26/4.0 - Xếp loại Giỏi), có nền tảng vững chắc về kỹ thuật phần mềm với JavaScript, TypeScript, SQL kết hợp kinh nghiệm thực chiến về kiểm thử chức năng, kiểm thử API (Postman) và tự động hóa kiểm thử web với Cypress. Kinh nghiệm thực tế tại HomeNest Software đặc tả kịch bản kiểm thử BDD (Given-When-Then), quản trị phân loại lỗi (Defect Triage) trên Jira và xác minh các bản dựng staging web/mobile theo logic nghiệp vụ phức tạp. Hiểu sâu kiến trúc DOM, xử lý bất đồng bộ (Promises, async/await) và nguyên lý kiểm thử mobile gray-box (Detox). Tự chủ, cầu tiến và sẵn sàng đóng góp vào các dự án kiểm thử tự động từ xa (Remote).

Kỹ Năng Kiểm Thử & Kỹ Thuật Trọng Tâm
  • Kiểm thử Tự động & Phương pháp QA: Automated Web E2E Testing (Cypress — assertions, custom commands, stubbing API với cy.intercept), Nguyên lý Kiểm thử Mobile Gray-Box (Detox — matchers, actions, đồng bộ luồng test), Functional Testing, Smoke Testing, Regression Testing, Cross-Browser Testing.
  • Thiết kế Test Case & Quản trị Lỗi: Đặc tả kịch bản BDD (Given-When-Then acceptance criteria), Phân tích giá trị biên (Boundary Value Analysis), Phân vùng tương đương, Kiểm thử phủ định (Negative Testing), Quản lý lỗi trên Jira & Phân tích nguyên nhân gốc (Root Cause).
  • Ngôn ngữ Lập trình & Kịch bản: TypeScript, JavaScript (ES6+, Async/Await, Xử lý DOM, cấu trúc dữ liệu JSON), SQL (PostgreSQL, MySQL — viết query kiểm tra đối soát dữ liệu, multi-table joins).
  • Kiểm thử API & Công cụ Network: Postman (Tự động hóa test script, collection runners, biến môi trường, test boundary values), RESTful APIs, Đặc tả OpenAPI 3.0 / JSON Schema validation, Chrome DevTools (Network tab, Console, Application state).
  • SDLC, DevOps & Hợp tác: Agile/Scrum, Git/GitHub (Branching, Pull Requests, giải quyết xung đột), Docker Compose cơ bản, Quy trình CI/CD; Tiếng Anh kỹ thuật (Đọc hiểu tài liệu chuyên ngành, viết bug ticket có cấu trúc và tài liệu test case), Tiếng Việt (Bản ngữ).
