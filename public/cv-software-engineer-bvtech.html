Kỹ sư Hệ thống Thông tin (IUH, GPA 3.26/4.0 · Đã hoàn thành toàn bộ chương trình · Sẵn sàng làm việc Full-time ngay) với tư duy logic thuật toán vững, nền tảng phân tích hệ thống bài bản và năng lực lập trình phát triển phần mềm toàn diện (JavaScript/TypeScript, PHP OOP & MVC, Python, SQL). Có kinh nghiệm thực chiến trong thiết kế RESTful API (OpenAPI 3.0), mô hình hóa và tối ưu CSDL quan hệ 3NF (MySQL, PostgreSQL), kiểm soát giao dịch ACID và giải quyết triệt để bài toán đồng thời (Pessimistic Locking SELECT ... FOR UPDATE). Tích hợp thành công các giải pháp công nghệ mới gồm AI Tool Calling tra cứu dữ liệu thời gian thực (đang vận hành Live tại tracking.nexus-ex.site) và hàng đợi thông điệp RabbitMQ. Tinh thần kỷ luật, tư duy sản phẩm hướng đến người dùng cuối, chú trọng chất lượng mã nguồn sạch (Clean Code), và mong muốn cống hiến lâu dài cùng hệ sinh thái công nghệ BVTech Việt Nam.

Dự án 1: "Hỗ Trợ Cuộc Sống" — Nền tảng Dịch vụ Đa tiện ích & Số hóa Quy trình Doanh nghiệp
  • Đặc tả Kiến trúc & Mô hình hóa Dữ liệu (Technical Specs & API Schema): Phân tích yêu cầu nghiệp vụ hệ thống đa dịch vụ (sửa chữa tại nhà, gọi xe ngắn, xe ghép, tuyển dụng); chuyển hóa quy trình thành tài liệu đặc tả kỹ thuật (PRD), mô hình hóa JSON data models và đặc tả RESTful API theo chuẩn OpenAPI 3.0; đối chiếu kiểm tra nguyên mẫu Figma với lược đồ CSDL quan hệ, loại bỏ hoàn toàn sai lệch giao thức trước khi đội ngũ lập trình bắt đầu sprint.
  • Thiết kế Máy trạng thái Đấu giá & Khóa dữ liệu (State-Driven Dynamic Bidding): Giải quyết triệt để tranh chấp giá và xung đột giao dịch bằng cách thiết kế máy trạng thái (State Machine) điều phối toàn diện vòng đời đơn: khởi tạo ↔ đề xuất giá ↔ phản hồi ↔ chấp nhận/từ chối với TTL tự động hủy; chỉ định cơ chế khóa trạng thái (status locking) và rào chắn race-condition chặt chẽ để đội backend triển khai chuẩn xác.
  • Tối ưu hóa Chi phí API Bản đồ & Tải thiết bị (Event-Driven GPS Optimization): Xử lý dứt điểm tình trạng vượt ngân sách gọi API bản đồ bên thứ ba và hao pin thiết bị bằng cơ chế làm mới tọa độ theo sự kiện (Event-driven Checkpoint — chỉ kích hoạt cập nhật khi trạng thái đơn hàng thay đổi thay vì liên tục polling), tiết kiệm hơn 60% chi phí gọi dịch vụ ngoài mà vẫn đảm bảo tính toàn vẹn dữ liệu hành trình.
  • Kiểm thử Tích hợp & Quản lý Lỗi (QA/UAT & Defect Triage): Trực tiếp xây dựng bộ kịch bản kiểm thử API bằng Postman, thực hiện kiểm thử chức năng và luồng dữ liệu trên môi trường Staging; ghi nhận, phân loại và điều phối xử lý lỗi (Defect Triage qua Jira) cùng đội ngũ lập trình qua 3+ chu kỳ phát hành sản phẩm, đảm bảo hệ thống đạt độ ổn định cao trước khi bàn giao.
